🤖 AI Document Simplifier
📌 Overview

AI Document Simplifier is a Streamlit-based application that simplifies complex PDF
documents by generating concise summaries and key points using AI.

🚀 Features

Upload and process PDF documents
Extracts text using PyMuPDF
Generates simplified summaries using AI (Gemini API)
Highlights key points for quick understanding
Interactive and user-friendly interface using Streamlit

⚙️ Tech Stack

Python
Streamlit
PyMuPDF
Google Gemini API

🧠 How It Works

User uploads a PDF document
Text is extracted using PyMuPDF
AI processes the content
System generates:
Summary
Key points
